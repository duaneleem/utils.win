# Duane's Windows 11 Utilities

A collection of Windows batch scripts and utilities designed to enhance productivity and resolve common issues on Windows 11.

## Utilities

### [Restart Explorer](restart-explorer/)

A Windows batch script utility that restarts the Windows Explorer process (explorer.exe) to resolve icon and image display issues in Windows 11. This script terminates the current Explorer instance and automatically restarts it, refreshing the desktop environment and file system icons.

## Usage

Each utility is a standalone batch script (`.bat` file) that can be executed directly by double-clicking or from the command prompt. No installation is required.

## Requirements

- Windows 11
- Administrator privileges (may be required for some utilities)
